# Instruções do front end

- Antes de criar ou alterar uma tela, leia `STYLE-THINK.md` e siga as decisões visuais registradas.
- Use Tailwind CSS para layout, cores, espaçamento, tipografia, responsividade e estados dos componentes.
- Evite escrever estilos em SCSS ou CSS puro para regras que podem ser expressas com classes Tailwind.
- Se uma necessidade visual não puder ser atendida adequadamente com Tailwind, prefira uma solução nativa do HTML/SVG. Adicione CSS específico somente quando necessário e mantenha esse código pequeno e localizado.
- Preserve a identidade visual aprovada e os ajustes manuais existentes.
- Mantenha a formatação dos arquivos próximos e revise a indentação antes de concluir.
